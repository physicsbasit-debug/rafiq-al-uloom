# Phase 6-7C4f — Grade 9 Lesson 1-1 Golden learning system

This patch applies the Golden lesson rules to the four student learning elements without rebuilding the accepted lesson baseline.

- Review: 5 progressively demanding items; visuals only where they carry information.
- Activity: a three-stage visual mission with decisions and sequence ordering; no written-response field.
- Game: four mature visual decision rounds with immediate feedback and skill summary.
- Mastery: five new situations, distinct from review, with a student-facing “أتقنت / راجع” summary.
- Internal metadata stores difficulty, cognitive level, visual role, source basis, and mastery dimension. It is not rendered in the student UI.

Source basis used during design: Grade 9 Student Book lesson 1-1, Activity Book exercise 1-1 SI, and Teacher Guide guidance for the shared 1-1/1-2 block.

No commit, push, db push, migration, or production deployment.
