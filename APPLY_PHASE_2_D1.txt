لا تحتوي الحزمة أي تعديل على quiz-engine.ts أو scoring.ts أو Auth.

بعد رفع محتويات ZIP إلى GitHub:

1. اسحب آخر نسخة:

   git pull origin main

2. تحقق من نطاق الالتزام:

   git show --stat --oneline -1

3. افحص التنسيق:

   npx prettier --check \
     tests/integration/supabase-mastery-results.integration.ts \
     docs/PHASE_2_D1_DATABASE_DESIGN.md \
     README_PHASE_2_D1.md

4. إذا ظهر تحذير Prettier:

   npx prettier --write \
     tests/integration/supabase-mastery-results.integration.ts \
     docs/PHASE_2_D1_DATABASE_DESIGN.md \
     README_PHASE_2_D1.md

   git add \
     tests/integration/supabase-mastery-results.integration.ts \
     docs/PHASE_2_D1_DATABASE_DESIGN.md \
     README_PHASE_2_D1.md

   git commit -m "style: format phase 2 d1 persistence files"
   git push origin main

5. تأكد أن Supabase تعمل:

   npx supabase status

6. أعد بناء قاعدة البيانات:

   npx supabase db reset

7. شغّل اختبارات Supabase كلها:

   npm run test:supabase

8. شغّل الاختبارات الأساسية وفحوص المشروع:

   npm test
   npm run build
   npm run lint
   npx prettier --check .
   git diff --check

9. افحص الحالة:

   git status
   git log -1 --oneline
