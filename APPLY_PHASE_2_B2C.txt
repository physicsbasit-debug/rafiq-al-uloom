Phase 2-B2c application steps

1. Copy the package contents over the repository root.
2. Install the pinned development dependency in Codespaces:
   npm install --save-dev --save-exact tsx@4.23.1
3. Regenerate the SQL file:
   npx tsx scripts/generate-supabase-seed.ts
4. Run the generator a second time and verify the file is unchanged.
5. Run:
   npx supabase db reset
   npm run build
   npm run lint
   npm run test
   npx prettier --check .
   git status

Expected new Vitest file:
  tests/seed/generate-supabase-seed.test.ts (7 tests)

The package deliberately does not include package.json or package-lock.json,
because npm must update them against the current repository state.
