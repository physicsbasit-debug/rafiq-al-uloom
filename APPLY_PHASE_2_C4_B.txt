2) في Codespaces اسحب التحديث:

git pull origin main

3) تحقق من وصول الملفات:

ls tests/integration/supabase-authorization-bypass.integration.ts

sed -n '1,420p' tests/integration/supabase-authorization-bypass.integration.ts
sed -n '280,390p' tests/integration/supabase-profiles-authorization.integration.ts
sed -n '1,320p' README_PHASE_2_C4_B.md

5) اطلب من كلاود التحقق خصوصًا من:

- أن الاختبارات تتجاوز React وauthorizeOperation بالكامل.
- استخدام جلسة مستقلة حقيقية لكل هوية.
- الفصل بين 42501 الناتج عن غياب GRANT وبين الصفوف الفارغة الناتجة عن RLS.
- أن حمولة INSERT كاملة وصحيحة وبلا .select() أو RETURNING.
- التحقق الإداري من عدم تغير البيانات بعد كل كتابة مرفوضة.
- رفض student وteacher وreviewer لعمليات INSERT وUPDATE وDELETE.
- رفض reviewer لتغيير status إلى approved.
- رفض تعديل display_name وrole وstatus لكل دور نشط.
- توسيع اختبار approved القائم إلى student وteacher وreviewer دون إنشاء اختبار حالة موازٍ.
- عدم تعديل أي Migration أو ملف داخل src/.

6) لا تشغّل الفحوص قبل اعتماد كلاود للملفات الفعلية.

npx supabase db reset
